1. Use the supplied sugya boundaries exactly and verify every conclusion against

2. Identify every materially used source, including textual sources, named or
   anonymous authorities, historical incidents, practical examples, logical
   principles, hermeneutic methods, customs, and aggadic materials.

3. Do not create a separate source merely because a speaker makes a procedural
   statement. Include a speaker as a source only when the speaker's authority,

4. Assign each source:
   - one source type;
   - one authority rank;
   - one structural centrality score;
   - one primary role;
   - any direct dependency;

   - a confidence score.

5. Group sources by meaningful shared function or theme. Do not create decorative

6. Choose exactly one central source per sugya. This is the source around which the
   largest part of the discussion turns, not automatically the highest-ranked source.

7. Record only direct dependencies. Do not infer a complete dependency graph.

8. Evaluate the supplied boundary using source structure alone. Explain whether a
   distinct source cluster, central source, or authority transition supports it.
